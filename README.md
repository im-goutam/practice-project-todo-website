# Taskly – Todo List App 🚀

Taskly is a simple and interactive Todo List application that helps users manage their daily tasks efficiently. Users can add tasks, assign priorities, and filter them based on their completion status.

## ✨ Features

- **Add Tasks:** Easily add new tasks to your todo list.
- **Task Priorities:** Assign Low, Medium, or High priority to tasks.
- **Filter Tasks:** Filter tasks using three categories:
  - All – View all tasks.
  - Active – View pending tasks.
  - Done – View completed tasks.
- **Task Management:** Keep track of your daily tasks.

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
